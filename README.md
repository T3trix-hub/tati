# Тати студио — сайт студии красоты

Многостраничный статический сайт для студии красоты «Тати студио» (Минск, ул. Гурского, 44, корп. 3). Чистые HTML, CSS и JavaScript, без сборки. В сайте много текстов (описания услуг, «как проходит визит», FAQ), чтобы страницы были содержательными.

## Страницы
- `index.html` — главная: рейтинг, описание, услуги, как проходит визит, удобства
- `services.html` — услуги и цены с описаниями
- `about.html` — о студии, подход, что нужно знать
- `faq.html` — вопросы и ответы
- `contacts.html` — адрес, телефоны, мессенджеры, карта

## Структура
`style.css`, `main.js` (меню и плавное появление), иконки `favicon*` и `apple-touch-icon.png`, фото `images/facade.jpg`.

## Запуск
`python3 -m http.server 8000` и открыть http://localhost:8000

## GitHub Pages
Загрузите содержимое папки в корень репозитория, затем Settings → Pages → Deploy from a branch → `main` / `(root)`.

## Что править
- **Цены** — `services.html`. Указаны три цены на женские стрижки с Яндекс Карт (40, 33, 25 Br). Для остальных замените `<span class="pr ask">цену уточняйте</span>` на `<span class="pr">20 Br</span>`.
- **Телефоны и мессенджеры** — в футере каждой страницы и в `contacts.html`.
- **Фото** — на сайте одно фото (фасад). Добавьте фото интерьера и работ в `images/` и замените.
- **Время работы** — не указано. Добавьте в `contacts.html`.
- **Цвета** — переменные в начале `style.css`. Шрифты: Lora и Nunito (Google Fonts).

Данные взяты с карточки на Яндекс Картах.
